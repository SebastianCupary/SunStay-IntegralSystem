# SunStay API Documentation

## Overview

SunStay exposes a REST API under the `/api` prefix. All internal modules require authentication and role-based authorization.

## Planned Route Structure

- `POST /api/auth` — Authentication
- `GET/POST /api/users` — User management
- `GET/POST /api/roles` — Role management
- `GET/POST /api/reservations` — Reservation management
- `GET/POST /api/guests` — Guest management
- `GET/POST /api/rooms` — Room management
- `GET/POST /api/billing` — Billing and invoices
- `GET/POST /api/inventory` — Inventory management
- `GET/POST /api/staff` — Staff management
- `GET/POST /api/attendance` — Staff attendance
- `GET/POST /api/common-areas` — Common area management
- `GET/POST /api/reports` — Report generation

Detailed endpoint documentation will be added as modules are implemented.
