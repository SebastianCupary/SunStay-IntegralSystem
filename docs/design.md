# SunStay Design Documentation

## Visual Identity

- Primary color: `#0d4c6f`
- Accent color: `#f5a623`
- Base font size: `14px`
- Spacing system: `8px` base unit

## Layout

- Desktop-first administrative dashboard
- Clean sidebar navigation
- Top header with user profile menu
- Module pages with title, description/breadcrumb, action button, search/filters

## UI Components

The component library will include:

- KPI cards
- Data tables with filters
- Forms with validation
- Modals and drawers
- Status badges
- Charts for reports and dashboards
- Responsive views for mobile operational tasks

Detailed component specifications will be added as UI components are implemented.
